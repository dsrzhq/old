# Timón · interactive demo

Public demo of **Timón**, the construction-control app for an Ontario architect-builder:
projects, expenses, unit costs and payroll. This repository hosts the static demo only.

**Live:** <https://dsrzhq.github.io/old/>

> **Not the real app.** No backend, no login and no money moves: camera and AI are simulated and
> **all data is sample data** (two fictional Ontario projects, CAD). The UI is in Canadian English;
> add `?lang=es` to the URL for the Spanish version.
